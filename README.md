# Design of a Real-Time Web Security Model for Detecting Website Defacement Attacks Using Hybrid Algorithm

## 🔐 About the Project

A real-time web security model designed to detect website defacement attacks by identifying unauthorized changes in webpage content.

The system uses a hybrid detection approach that combines machine learning, pattern matching, content integrity verification, and text similarity analysis to improve the accuracy of defacement detection.

## 🎯 Objective

The main objective of this project is to detect unauthorized modifications made to websites and provide an early warning against website defacement attacks.

## 🚀 Key Features

- Real-time website defacement detection
- Machine learning-based detection using Random Forest
- Pattern matching for known malicious changes
- SHA-256 based content integrity verification
- Text similarity analysis
- Detection of suspicious webpage modifications
- Reduced false alerts through a hybrid detection approach

## 🧠 Detection Approach

The system combines multiple techniques:

1. **Random Forest** – analyzes website features to identify potential defacement.
2. **Pattern Matching** – detects known suspicious or malicious patterns.
3. **SHA-256 Hashing** – verifies the integrity of website content.
4. **Text Similarity Analysis** – compares webpage content to identify significant changes.

These techniques work together as a hybrid detection model.
